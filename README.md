# Política de Privacidade — Arkiva

**Última atualização:** 10 de junho de 2026

Esta Política de Privacidade descreve como o aplicativo **Arkiva** trata informações e dados inseridos pelo usuário.

O Arkiva foi criado para ajudar você a organizar documentos, contas, garantias, manutenções, compromissos, vacinas, anotações, checklists, lembretes e outras informações importantes do dia a dia, com foco em simplicidade, controle local e privacidade.

> **Resumo rápido:** o Arkiva não exige login, não possui conta de usuário, não sincroniza seus dados com nuvem própria, não vende dados, não exibe anúncios personalizados e não utiliza analytics ou telemetria. Os dados cadastrados ficam armazenados localmente no seu dispositivo.  
> A única funcionalidade que pode envolver envio de conteúdo para a internet é o recurso opcional de criação facilitada com IA, que utiliza o Gemini para interpretar o texto digitado pelo usuário e transformá-lo em um item dentro do Arkiva.

## 2. Dados que o Arkiva armazena no dispositivo

O Arkiva permite que você cadastre informações como:

- títulos e descrições de itens;
- tipo do item, como documento, garantia, manutenção, conta, compromisso, vacina, anotação, checklist ou outros;
- categorias;
- datas importantes;
- lembretes;
- campos personalizados;
- anexos adicionados pelo usuário, como imagens ou documentos;
- itens arquivados;
- configurações locais do aplicativo, como preferência de tema.

Essas informações são armazenadas localmente no seu próprio dispositivo.

O Arkiva **não cria uma conta para você** e **não exige login** para funcionar.

---

## 3. Armazenamento local

Os dados cadastrados no Arkiva ficam salvos no armazenamento local do aplicativo, no dispositivo em que ele está instalado.

Isso significa que:

- o Arkiva não possui servidor próprio para armazenar seus dados;
- o Arkiva não sincroniza automaticamente seus dados com nuvem;
- o Arkiva não disponibiliza seus dados para outros usuários;
- se o aplicativo for desinstalado ou se os dados do app forem apagados pelo sistema, as informações locais podem ser perdidas.

Caso o aplicativo ofereça recurso de exportação/importação de backup, esse arquivo será gerado a pedido do usuário. O usuário é responsável por guardar, mover, compartilhar ou excluir esse arquivo de backup.

---

## 4. Uso da funcionalidade com Gemini

O Arkiva pode oferecer uma funcionalidade opcional de criação facilitada de itens com IA.

Essa funcionalidade usa o **Gemini**, serviço de inteligência artificial do Google, para interpretar um texto digitado por você e sugerir a criação de um item estruturado dentro do Arkiva.

Exemplo: você pode digitar algo como:

> “Lembrar de pagar o seguro do carro em 10 de agosto”

A IA pode ajudar a transformar esse texto em um item com título, tipo, data e lembrete.

### 4.1. Quando dados são enviados ao Gemini

Dados somente são enviados ao Gemini quando você usa a funcionalidade de criação facilitada com IA.

O conteúdo enviado pode incluir o texto livre que você digitou para que a IA interprete sua solicitação.

O Arkiva não envia automaticamente todo o seu banco de dados, anexos, documentos salvos, histórico completo ou outros itens cadastrados no aplicativo para o Gemini.

### 4.2. Finalidade do envio

O texto é enviado ao Gemini exclusivamente para permitir que a IA interprete sua solicitação e ajude a criar ou preencher um item dentro do Arkiva.

### 4.3. Serviço de terceiro

O Gemini é um serviço fornecido pelo Google. Ao utilizar a funcionalidade de IA, o conteúdo enviado poderá ser processado pelo Google conforme os termos e políticas aplicáveis aos serviços Gemini/API do Google.

Recomendamos que você evite inserir informações extremamente sensíveis, sigilosas ou confidenciais no campo de criação com IA, especialmente se não quiser que esse conteúdo seja enviado para processamento externo.

### 4.4. Uso opcional

O uso da funcionalidade com IA é opcional.

Você pode utilizar o Arkiva manualmente, criando e editando seus itens sem usar o Gemini.

## 5. Dados que o Arkiva não coleta

O Arkiva não coleta intencionalmente:

- nome;
- e-mail;
- telefone;
- CPF;
- endereço;
- localização;
- contatos;
- dados de pagamento;
- dados de navegação na web;
- identificadores para publicidade;
- histórico de uso para analytics;
- telemetria de comportamento;
- informações para venda ou compartilhamento comercial.

O aplicativo também não utiliza login próprio, conta em servidor próprio ou painel web para acessar os dados do usuário.

---

## 6. Anexos e documentos adicionados pelo usuário

O Arkiva pode permitir que você adicione anexos, como fotos ou documentos, aos itens cadastrados.

Esses anexos permanecem no dispositivo, conforme o funcionamento do Android e das permissões concedidas pelo usuário.

O Arkiva não envia seus anexos para servidores próprios e não compartilha esses arquivos automaticamente com terceiros.

Se você selecionar manualmente algum arquivo, exportar um backup ou compartilhar informações usando recursos do próprio sistema Android, o tratamento desses dados poderá depender dos aplicativos ou serviços escolhidos por você.

---

## 7. Lembretes e notificações

O Arkiva pode usar notificações locais para lembrar você sobre datas importantes, vencimentos, compromissos e outros itens cadastrados.

Essas notificações são geradas localmente no dispositivo.

O Arkiva não precisa enviar seus lembretes para um servidor externo para que as notificações locais funcionem.

Dependendo da versão do Android, o sistema poderá solicitar permissão para envio de notificações.

---

## 8. Permissões do dispositivo

O Arkiva pode solicitar permissões necessárias para o funcionamento de recursos específicos, como:

- envio de notificações;
- acesso a arquivos ou imagens selecionados pelo usuário;
- uso de recursos do sistema para armazenar anexos ou permitir importação/exportação.

As permissões são usadas apenas para viabilizar funcionalidades do aplicativo.

Você pode revisar ou alterar permissões do aplicativo nas configurações do Android.

---

## 9. Compartilhamento de dados

O Arkiva não vende, aluga ou comercializa dados pessoais.

O Arkiva não compartilha dados com anunciantes, redes de anúncios, corretores de dados ou plataformas de analytics.

A única situação em que conteúdo pode sair do dispositivo, dentro do funcionamento normal do aplicativo, é quando o usuário utiliza voluntariamente o recurso de criação facilitada com IA integrado ao Gemini, conforme explicado nesta Política.

Além disso, o usuário pode, por conta própria, exportar arquivos, compartilhar anexos ou mover backups usando recursos do Android ou outros aplicativos. Nesses casos, o compartilhamento depende da ação escolhida pelo próprio usuário.

---

## 10. Segurança

O Arkiva foi projetado para reduzir a exposição de dados, mantendo as informações localmente no dispositivo e evitando login, nuvem própria, analytics e rastreamento.

Mesmo assim, nenhum sistema é absolutamente imune a riscos.

A segurança dos dados também depende de medidas do próprio usuário, como:

- manter o dispositivo protegido por senha, PIN, biometria ou outro bloqueio de tela;
- manter o sistema Android atualizado;
- evitar instalar aplicativos de fontes desconhecidas;
- proteger arquivos de backup exportados;
- evitar inserir informações altamente sensíveis na funcionalidade com IA.

---

## 11. Retenção e exclusão de dados

Como os dados do Arkiva ficam armazenados localmente, você pode excluir informações diretamente no aplicativo, quando a funcionalidade estiver disponível.

Você também pode remover os dados do Arkiva pelas configurações do Android ou desinstalar o aplicativo.

Ao desinstalar o app ou limpar os dados do aplicativo pelo sistema, as informações armazenadas localmente podem ser apagadas de forma permanente, salvo se você tiver criado e guardado um backup.

O Arkiva não possui uma conta online do usuário e, portanto, não mantém um cadastro remoto para ser excluído em servidor próprio.

---

## 12. Backup e exportação

Caso disponível na versão instalada, o recurso de backup permite exportar dados para um arquivo.

Esse arquivo é criado a pedido do usuário e deve ser guardado com cuidado.

O Arkiva não controla onde você salva, envia ou compartilha esse arquivo após a exportação.

Se o arquivo de backup contiver informações pessoais, documentos ou dados sensíveis, trate-o como um arquivo privado.

---

## 13. Crianças e adolescentes

O Arkiva não é direcionado especificamente a crianças.

O aplicativo foi pensado para organização pessoal de rotina adulta, como documentos, vencimentos, garantias, contas e compromissos.

Se um responsável entender que uma criança ou adolescente inseriu dados no aplicativo de forma inadequada, recomenda-se excluir os dados diretamente no dispositivo.

---

## 14. Serviços de terceiros

O Arkiva pode utilizar serviços de terceiros apenas quando necessários para funcionalidades específicas.

Atualmente, a principal integração externa prevista é:

- **Gemini / Google**: usado opcionalmente para interpretar textos digitados pelo usuário e facilitar a criação de itens no Arkiva.

O tratamento de dados realizado por serviços de terceiros é regido também pelos termos e políticas desses serviços.
